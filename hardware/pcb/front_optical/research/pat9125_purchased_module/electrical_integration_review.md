# PAT9125EL-TKIT 成品前板与 ESP32 后板独立电气审查

日期：2026-10-07。只读核验当前后板文件，未修改在线 EDA、后板网表、制造文件或根开发文档。用户已选择图片所示 14×15 mm 成品前板；选型决定已成立，本文区分已确认的后板接入能力和成品模块仍待核实的条件。

## 1. 直接核验依据

- 后板网表：`rear_mainboard/restore_esp32/review/ESP32S3_V03_latest.enet`，不是旧 nRF 版本。
- 后板供电容差：`rear_mainboard/restore_esp32/research/final_electrical_release_review.md`。
- ESP32-S3-MINI-1 原厂手册（项目归档）：`references/pcb_selection/esp_mini.txt`，DC characteristics 中 VIH≥0.75×VDD，VIL≤0.25×VDD。
- 用户提供商品图片：板框 14×15 mm，五个端子文字为 VDD / SCL / SDA / MOT / GND，7-bit I²C 地址示意为 0x75；实物、观察面与脚序仍须按到货丝印核对。
- 本轮用户新增原厂一页参数图：PAT9125EL 的高电压供电配置 VDD=2.1～3.6 V，低电压配置 VDD=1.7～1.9 V；VLD=2.7～3.6 V；EL-TKIT 是 I²C 版本。该页给的是芯片条件，不能等价成商品模块 VDD 端子的允许输入范围，也未闭合 GPIO 电气规格。

## 2. 后板已确认的拓扑与接线

| 后板接口/网络 | 当前真实电路 | 成品前板功能 |
|---|---|---|
| J401-1 VOPT | 3V45 经 R404=0 Ω；C403=4.7 µF、C404=100 nF 对地 | VDD，供电接入待模块条件闭合 |
| J401-2 GND | 系统 GND | GND |
| J401-3 OPT_SCL_C | R405=47 Ω → OPT_SCL → U201 模块脚12 / GPIO8 | SCL |
| J401-4 OPT_SDA_C | R406=47 Ω → OPT_SDA → U201 模块脚13 / GPIO9 | SDA |
| J401-5 OPT_MOTION_C | R407=1 kΩ → OPT_MOTION → U201 模块脚14 / GPIO10 | MOT（可在首轮轮询时暂不接） |
| J401-6 GND | 第二个系统 GND 触点 | 可接成品板同一 GND；或单独绝缘不用 |

后板 J401 为 JST SM06B-SRSS-TB(LF)(SN)，6 位、1.0 mm SH 系列、侧插；不等于图中成品板五孔接口。需要六位配套线束到五功能焊点的转接，不能按位置顺序一一对插。J401 的 7/8 为连接器机械接地焊盘，不是线束触点。成品板孔距未由图片正式确认，不擅自冻结为 2.54 mm。

R408、R409、R410 分别为 SCL / SDA / MOT 到 VOPT 的后板上拉，当前均 DNP，网表 Add into BOM=no。保持 DNP，不应为了成品板盲目补装。

R405/R406 的 47 Ω 有助于限制快速边沿振铃；R407 的 1 kΩ 是输入支路串阻。它们均不是电平转换、稳压或断电隔离器，不能将 5 V 信号变成 3.3 V。

## 3. 供电兼容判定

后板 VOPT 不是受控 3.3 V LDO 输出，而是 3V45 经过 0 Ω 引出的电源。既有静态工程包络为 3.3892～3.5114 V（额外保守温差预算）；启动过冲、纹波和压降仍需实测，芯片供电焊点必须满足各自范围。

新增原厂页支持以下窄结论：若成品模块采用高电压配置，且 VDD 输入直供或正确处理至芯片 VDD/VLD，则 3.45 V 标称以及上述静态包络在芯片 3.6 V 上限内。它不能证明商品板就是该接法。

模块 U2 的型号、输入/输出关系和原理图未知。U2 可能影响输入最小值、激光供电、内部逻辑电压和上电过程。不能通过外形或模糊顶标认定其是 3.3 V LDO，也不能把该模块默认归类为“只接 3.3 V”或“可接 5 V”。即使芯片高电压配置允许 3.45 V，仍须确认模块 VDD 端可在实际 VOPT 包络工作。

如卖家只给典型 3.3 V 而未给范围，尚不足以直接批准 3.45 V。若模块要求 5 V 输入，当前 J401 无 5 V，需要另作供电适配；不能用加大串联电阻、二极管压降或盲目补装线束 LDO来替代范围核验。若考虑在线束/模块侧增加 3.3 V LDO，最低 3V45 与 3.3 V 之间仅约 89 mV 静态余量，还应核算最大负载、最差压差、线损和启动，不能默认任何 LDO 可用。

## 4. I²C 电平及上拉

ESP32 GPIO8/9 应采用开漏驱动，关闭内部上拉。GPIO10 只设输入；初始上电和复位阶段不主动驱动光学信号。

如果成品模块 SCL/SDA 已上拉到合规的局部 3.3 V，那么 ESP 主电源 3.45 V 与 3.3 V I²C 高电平通常匹配：名义 VIH 要求为 2.5875 V；即把 ESP 电源上限 3.6 V 代入，VIH 需求为 2.70 V。仍需用模块实际最小上拉电压、泄漏电流、线束压降/噪声核算，不仅看“3.3 V”标签。

如果模块上拉至 1.8 V，则不满足当前 ESP 的高电平门限，需要合适的双向 I²C 电平转换或厂家确认的另一接法。若上拉至输入 VDD/VOPT，则还需核对芯片 I/O 允许范围及模块内部电压配置；芯片 VDD 的范围不自动证明任何 I/O 引脚可同范围输入。若上拉至 5 V，禁止直连 ESP。

须由卖家原理图或到货断电电阻/通断测量明确 R1/R2 等上拉所接电源及阻值，随后用示波器检查总线上升时间与低电平。不能仅凭照片上两只“512”电阻认定它们一定是 I²C 上拉。首次通讯用 100 kHz 开始；提速须根据总线电容与模块时序完成测试。后板两只 47 Ω 通常可保留，低电平最差条件仍需含 GPIO 和 PAT 的 VOL，以及串阻电流压降核验。

## 5. MOT 与最小接入

MOT 的开漏/推挽、有效极性、保持/清除条件和高电平电压尚未由模块资料确认。开漏需要上拉至已核实的合法逻辑电源，不能默认在 ESP 侧打开 3V45 内部上拉；推挽则核对模块 VOH(min)≥ESP VIH(max)、VOL(max)≤ESP VIL(min)。1 kΩ 串阻不替代这些条件。

首轮可用四根功能线 VDD/GND/SCL/SDA 完成通信和位移寄存器轮询，MOT 先不接；这只是调试简化方案，最终仍保留 J401-5 及五线线束能力。轮询代码必须按 PAT 的状态与 X/Y 读取/清除规则执行，合理间隔避免累计位移溢出；不承诺单纯轮询频率等于光学采样频率。当前光学使用独立 GPIO8/9 总线，JY901S 用 UART。

## 6. 上电、掉电与反灌

当前 R404=0 Ω，没有光学独立负载开关，也不能通过固件关断 VOPT。正常线束应由后板给模块供电、两板共地，避免模块另接外部电源时仍把电源/信号接回未上电后板。

首次连接与拆线均断电操作。上电稳定和模块启动延时满足后再发起 I²C；发读操作前 GPIO 为高阻/开漏释放且无内部上拉。前板局部电容/LDO可能使掉电速度不同，需要核对传感器 I/O 断电容限，观察掉电时 GPIO 是否高于未上电域允许值。47 Ω/1 kΩ 串阻不保证断电防反灌；若必须独立供电、热插拔或独立开关前板，需另做电源时序/隔离设计，不能把现接口当作已支持。

## 7. 可交付结论与未闭合项

后板现有 J401、电源引出、GPIO 与串阻已具备接入该 I²C 模块所需的电路资源；使用成品板本身不要求改 MCU、改 GPIO 或重布后板。用户的正式选型可据此纳入当前方案。

然而“功能连接已确定”不等于“成品板可直接上电已证明”。只需围绕该确切商品取得：

1. 模块 VDD 输入范围及 U2/模块电源结构，确认实际 VOPT 全范围可用；
2. SCL/SDA/MOT 电平、上拉电源与阻值，MOT 输出类型和有效极性；
3. PAT9125EL-TKIT 初始化与位移读取例程/时序，核对上电等待和 I²C 0x75。

到货验证至少包含：断电接线核对、限流初次供电与内部电源测量、识别寄存器/I²C 应答、静止与双轴往返位移、MOT、BLE发送与USB连接条件下总线和电源波形。由实物确认供电/电平后，才能将“条件兼容”改为“已验证可接入”。本报告不授权制造下单，也未冻结成品板光学结构。
