# PAT9125EL-TKIT成品模块接入后板

日期：2026-10-07。选型已获用户确认；**按用户要求将后板J401改为五针顺序直通；五针网表和布线均已验证，严格PCB DRC=0、418焊盘网表0差异。** 后板采用ESP32-S3-MINI-1-N4R2，当前版本见[恢复目录](../../rear_R26/README.md)。

**本轮范围更新：**用户明确只要求确认接口顺序、I²C和高低电平连接方式，不继续追索模块供电资料。接口映射、TKIT的I²C类型与0x75地址已按现有资料核对；后板SCL/SDA采用开漏、关闭内部上拉，MOT为输入，按3.3V逻辑接入。若成品模块实际为3.3V逻辑，则与后板兼容。图片尚未标出模块实际上拉电压和MOT输出电平，这两项保留为到货核验，不将设计上的对应关系写成已实测。下方供电及验收内容作为后续接通和调试参考，不再作为本轮接口定义工作的前置输入。

## 1. 五芯直通排线定义（当前版本）

成品模块按卖家接口图的标注面、文字正向、焊盘在下方看，从左到右为VDD / SCL / SDA / MOT / GND。实际板先核对丝印和通断，背面顺序会镜像；不按淘宝图猜后板连接器左右顺序。

| 成品模块焊盘 | 新后板J401针号 | 后板真实连接 |
|---|---:|---|
| VDD | 1 | VOPT，经R404=0Ω接3V45 |
| SCL | 2 | OPT_SCL_C，经R405=47Ω → GPIO8 / MINI焊盘12 |
| SDA | 3 | OPT_SDA_C，经R406=47Ω → GPIO9 / MINI焊盘13 |
| MOT | 4 | OPT_MOTION_C，经R407=1kΩ → GPIO10 / MINI焊盘14 |
| GND | 5 | 后板GND |

后板J401采用 **JST SM05B-SRSS-TB(LF)(SN)，C136657，1.0mm间距、五针侧插**。从连接器电气1脚开始，排线五芯依次为VDD / SCL / SDA / MOT / GND；模块端按同一顺序焊入五个焊孔，无需交叉换序。J401固定焊脚6/7接地，仅用于固定，不属于线束触点。

线端选匹配JST SH 1.0mm五芯插头/尾线（SHR-05V-S系列）；模块端优先直接焊软线并做应力释放，避免竖装排针增加高度。**模块孔距尚未核实，不能把后板1.0mm插头当成可直接插到模块上的通用插头。**“直通”指五芯信号顺序一致，两端接口形态可以不同。断电按针号测通，不依赖线色；模块背面观察时顺序会镜像。

历史六针版本：SM06B-SRSS-TB，1=VOPT、2=GND、3=SCL、4=SDA、5=MOT、6=GND，固定脚7/8。该定义只用于识别旧板，**不得套用到新五针J401**。

微动仍接J402-1/2，对应TIP_RAW/GND、GPIO11，不经过成品模块，也不占MOT引脚。

## 2. 电气条件与处理

VOPT不是独立3.3V稳压输出：它由3V45经R404=0Ω引出，已有C403=4.7µF和C404=100nF去耦。既有额外保守静态预算为3.3892～3.5114V；启动过冲、纹波和压降仍须测量。

新摘要页确认PAT高电压接法VDD=2.1～3.6V、VLD=2.7～3.6V，因此裸芯片采用该接法时，后板标称值和上述静态区间符合要求。模块还包含未知U2，可能改变输入、电源与上拉条件；芯片允许电压不能直接作为模块允许电压。

到货调试时核验模块VDD入口、U2用途、芯片供电接法、SCL/SDA上拉电源和MOT输出类型/电平；按用户确定的本轮范围，不再为完成线序修改重复索取资料。

| 已确认的模块条件 | 接入处理 |
|---|---|
| 输入范围覆盖VOPT全工作区间，IO与ESP兼容 | 使用本表直接转接；测启动、纹波和总电流 |
| 模块要求其它输入电压或更大稳压压差 | 先确定供电适配，不盲接USB5V或电池原始端 |
| I²C为1.8V上拉 | 不满足当前ESP高电平门限，需要适配 |
| I²C或MOT输出为5V | 不可直连ESP，需处理电平 |

ESP输入高阈值按0.75×VDD预算：3.45V时2.5875V；取3.6V供电上限时2.70V。合规3.3V开漏上拉有静态裕量，1.8V没有；仍须检查实际电压、VOL、串阻压降和总线上升时间。

后板R408/R409/R410保持DNP；装上会拉到VOPT。在模块上拉路径未核实时不要补装，也不启用ESP内部上拉。SCL/SDA采用开漏；47Ω和1kΩ串阻不是电平转换器或断电隔离器。

## 3. 固件约定

- 光学I²C：SDA=GPIO9、SCL=GPIO8，先100kHz；ADS1115保持GPIO4/5，JY901S保持UART。
- 商品图标明ID_SEL接地，7位地址0x75。不要把8位读写地址当7位地址传入API。
- 按供应商对应驱动先验证芯片身份，再执行初始化。Prusa参考ID为0x31/0x91，可作为对照；实物不符不能静默忽略。
- 最小调试连接为VDD/GND/SCL/SDA，供电与I²C电平确认后轮询读取Δx/Δy。确认MOT电平、极性和清除方式后再接GPIO10。
- 所有通道使用ESP单调时间基准，记录读取前后时刻、序号、状态及原始位移。统一时间戳不等于已经达到固定同步精度。
- 光学方向按最终安装姿态标定；轮询频率不等于芯片实际采样频率。
