# R26 后板维护入口

最新电气/布线设计为2026-10-09的R26；2026-10-12补充裸板＋钢网、自行焊接资料，电路和Gerber没有更新。2026-11-06整理时保留设计源文件原始字节。

- `Rear_ESP32S3_R26.epro`：在嘉立创EDA专业版中导入完整工程，包含可编辑原理图、PCB及符号/封装。选择 Rear_Mainboard；工程内历史 Front_Optical 不制造。
- `Rear_ESP32S3_R26.epcb`：单独后板PCB布局布线。
- `后板当前原理图网表.enet`：电气连接核对。
- `后板_R26_制板文件.zip` / `后板_R26_钢网原始层.zip`：Gerber及锡膏层。
- `BOM_FIT_REVIEW.csv`：112件总装清单；`DNP_PCB_ONLY_REVIEW.csv`：不焊与裸测试点。工厂SMT/CPL文件保留供审阅，当前采购方式为自焊，不自动下单。
- `cam_top.png` / `cam_bottom.png`：制造图；`verification/`为R26当时的核验记录。
- `本版说明.md`、`制造与装配要求.md`等为当时设计记录，其中“未下单/未实测”描述对应当时，最新实物状态见[已知问题](../../docs/KNOWN_ISSUES.md)。

特别保留：盘中孔树脂填孔整平与电镀盖帽、指定四层叠层和USB阻抗要求。J401字高的工艺复核见自焊指南。原生DRC=0不代表已经排除实物电源故障。
