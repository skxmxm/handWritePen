# R26 装配说明

本轮移动11个底面器件；实装8件已同步两份CPL，DNP3件不进入贴片清单。必须使用R26工程/CPL/装配图，旧PDF及旧坐标不能混用。以下坐标为工程坐标，底层不自行镜像。

| 位号 | 装配 | 新中心X,Y（mm） | 绝对旋转 |
|---|---|---|---|
| R301 | FIT | 30.700, -0.750 | 270° |
| C302 | FIT | 28.800, -2.250 | 0° |
| R401 | FIT | 12.000, 5.000 | 180° |
| C401 | FIT | 11.100, 2.900 | 180° |
| R404 | FIT | 15.000, 5.000 | 180° |
| R405 | FIT | 22.000, 5.700 | 90° |
| R408 | DNP | 16.200, 7.700 | 180° |
| R409 | DNP | 19.300, 8.300 | 90° |
| R410 | DNP | 18.000, 5.800 | 90° |
| R503 | FIT | 47.000, 7.500 | 180° |
| R510 | FIT | 51.750, 6.800 | 180° |

R301是无极性电阻，本次由90°转到270°。C302的新位置为(28.80,−2.25) mm；旧PDF和R25位置已失效。

自动SMT110件使用BOM_FACTORY_SMT_110/CPL_FACTORY_SMT_110。U401=JY901S裸模块、J301=指套插座两件在回流后手焊，使用MANUAL_POST_REFLOW文件。完整装配参考112件。DNP元件默认不装，预留便于调试；完整器件轮廓保留于装配层。

D501/D502/D503使用LTST-C190KRKT，顶视图pad1阴极朝较小X；主控必须ESP32-S3-MINI-1-N4R2。按《制造与装配要求》核对极性、USB壳脚槽工序和JY901S手焊顺序。

板框与外部接口位置保持，现有壳体主要尺寸参考不变；实物插拔和内部走线试装仍需验证。
