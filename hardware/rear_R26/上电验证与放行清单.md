# ESP32 后板工程样板：制造核对与首件上电

更新：2026-10-07。适用 **ESP32-S3-MINI-1-N4R2、BLE、五针 J401** 当前后板。本文取代旧 BLE V0.2D4 清单；旧文已归档到 `restore_esp32/routing_review/history/`。接口依据[接口与固件输入](接口与固件输入.md)，具体版本以最终交付清单及哈希为准。

**当前工程样板制造输入已完成R23数字检查，原理图0 error、1项库属性提醒已审核。** 最终文件、9孔工艺清单、110＋2装配与哈希见production/R23交付包。下列涉及实物备料、厂方核稿及到板测试的项目仍需实际填写；未下单，用户已明确不要下单。

## 当前设计输入

| 项目 | 本版依据 |
|---|---|
| 主控与无线 | ESP32-S3-MINI-1-N4R2，4 MB Flash、2 MB PSRAM，主要 BLE；不采用旧 nRF 固件和烧录步骤 |
| 母板 / 装配包络 | 母板 70×24 mm；含模块天线的长度约 75 mm；不能仅用母板长检查外壳 |
| 制造叠层 | 四层、JLC04101H-3313，成品目标 1.00 mm ±10%，外铜 1 oz / 内铜 0.5 oz；L1–L2 介质 0.0994 mm、Dk 4.1 |
| USB 配对主干 | 顶层 0.15 mm 线宽 / 0.15 mm 铜边间距，L2 地参考；指定 90 Ω ±10% 阻抗控制，不允许随意替换默认 7628 叠层 |
| 电池 | 预留空间 5×12×21 mm；用户确认采用 ESP32 后的新电芯型号、容量及连续/脉冲放电能力尚待据实记录，不把旧 100 mA 能力当作当前结论 |
| 充电 | BQ25185，4.2 V 档，R104=5.1 kΩ；名义约 58.8 mA，保守计算范围 52.42～65.36 mA，须与实际电芯允许值匹配 |
| USB 输入限流 | 当前设计为 100 mA 档，计算约 80～98 mA；这是充电芯片输入设置，不是电池放电或台式电源通用硬上限 |
| 前光学模块 | PAT9125EL-TKIT 成品板，约 14×15 mm，五芯直通线；微动单独接 J402 |
| JY901S | 裸模块焊装到后板；无厂家回流依据时，默认完成主板 SMT 后人工焊装，不假设可随主板整体回流 |
| 皮肤电接口 | 2.5 mm 插座；测试从标准电阻开始，USB 接入时必须验证硬件关闭激励 |

官方叠层及计算证据见 [USB 阻抗报告](stackup_evidence/USB_90ohm_stackup.md)。当前尺寸对应厂家名义计算约 85.55～87.84 Ω，属于 90 Ω ±10% 范围；生产控制仍应按指定叠层与阻抗要求执行。树脂填孔及电镀盖帽能力已有[官方公开工艺依据](嘉立创工艺核实.md)，其中旧版孔数不作为当前生产数量。

## 制造文件核对：工程样板交付前完成

- [ ] 冻结唯一版本：原理图、PCB 原生源、可重开工程、Gerber、钻孔、BOM、CPL、装配图和本次检查结果来自同一最终快照，记录哈希。禁止混用旧 D4、历史六针 J401 或中间评审文件。
- [ ] 最终原生工程重新打开后，器件、焊盘、网络、走线、过孔与导出源一致；原理图到 PCB 逐脚核对，无遗失连接和异网连接。
- [ ] 最终 DRC 通过；重新生成真实铺铜，独立核对实际四层铜的连通、异网隔离、天线/IMU 禁区，以及 USB 下参考地。不能用过期派生铺铜或仅线路对象的结果代替。
- [ ] 制造 Gerber 保留原始铜、阻焊、板框及应有孔槽。重复导出的过孔钻孔记录只能去重一次；金属化连接器槽孔与非金属定位孔完整保留。
- [ ] 按最终 `VIA_IN_PAD_PROCESS.csv` 指定需要的孔位采用**过孔塞树脂＋电镀可焊铜帽**；不得用盖油、半塞油代替。当前数量从最终报告读取，不照抄历史孔数。
- [ ] 工艺说明写明 JLC04101H-3313、1.00 mm、铜厚及 USB 90 Ω ±10%；板厂拟采用其他叠层或改线宽间距时，先重新核对其计算与当前铜间距，再采用该生产稿。
- [ ] 最终丝印到实际露铜开窗满足制造间距；接口用途、引脚 1、极性、BOOT/RESET 可读且没有误标。装配层承担无法在板面完整放置的位号。
- [ ] BOM 的 FIT/DNP/PCB_ONLY 与真实锡膏、CPL 和装配图一致；默认 DNP 位不误贴，裸露测试区不误当采购连接器。U101 裸露焊盘锡膏覆盖与开窗以最终检查结果为准。
- [ ] **JY901S 标为后装人工焊接；2.5 mm 插座标为通孔后焊。** 两者应在总装 BOM 中保留，但不能未经区分地交给自动 SMT 当普通贴片件处理。主板 SMT、后焊和用户提供模块的交付范围在装配说明中明确。
- [ ] 元件实物型号/库存与 BOM 对应，USB-C、J401/J402、电池插座及 JY901S 焊盘朝向有装配图依据；不得未经核对替换功能、封装或耐压。

这组项目完成后可将文件标记为“工程样板 PCB＋SMT 交付版”。电池实测、续航和人体信号质量属于到板验收，不因尚未实测而一概阻止先制造可用台式电源调试的工程样板；接入真实电池前的规格和峰值匹配要求仍必须完成。

## 操作前必须知道的接口

脚号以 PCB 焊盘号和连接器定位图为准，不能按插头视角自行反向编号。

| 接口 / 控件 | 实际连接与操作 |
|---|---|
| J102 电池 | 1=VBAT、2=GND。测量实际线束极性后接入；不只凭红黑线色 |
| J103 温度 | 1=BAT_TS、2=GND；接实际电池温度检测，不是第二个电源口 |
| J104 电源控制测试区 | 1=PWR_EN、2=GND；短接到地关闭主电源 |
| USB-C | 充电及原生 USB Serial/JTAG 烧录；D−/D+ 对应 GPIO19/20 |
| SW201 / SW202 | SW201=BOOT(GPIO0)；SW202=RESET/EN |
| J501 调试测试区 | 1=UART0_TX(GPIO43)、2=UART0_RX(GPIO44)、3=MCU_EN、4=BOOT_N、5=GND、6=3V45参考 |
| J401 光学 | 1=VOPT(VDD)、2=SCL、3=SDA、4=MOT、5=GND；6/7为接地机械焊脚，不是信号脚 |
| J402 微动 | 1=TIP_RAW、2=GND；接开关 COM / NO，GPIO11 的 TIP_SW 低表示落笔 |
| J301 指套 | 1=E_SLEEVE、2=E_TIP，3/4为未用触点。两极均经过前端限流，不能把任一极直接改接电路 GND |
| J302 模拟测试区 | 依次 VREF、VEX、GSR_S、GSR_OUT、GSR_ADC、GND；7/8为附加地 |

J501 是 **UART0/EN/BOOT，不是 SWD**。外部 UART 用 3.3 V 逻辑，适配器 RX 接 J501-1，TX 接 J501-2，地接 J501-5；J501-6默认仅为目标电压参考。避免 USB、调试器及台式电源的多路供电互相倒灌。ESP32 原生 ROM 支持 USB 烧录，无需预先烧写应用 USB 引导程序；不为普通开发永久烧写 USB/JTAG 相关 eFuse。

## 首件准备与无源检查

- 建立记录：板号、制造包哈希、BOM版本、后装件批次、固件提交/配置、仪器及限流值；所有测试填写实测值和结果。
- 电池、指套和光学板先不接；JY901S 若尚未后焊，可先完成主板检查。主板 MCU 已经 SMT 时，通过 EN/固件隔离测试阶段，不要求拆下模块。
- 显微镜检查方向、连锡、虚焊、连接器固定脚和热焊盘；对不可见焊点使用合适的装配检查手段。检查 JY901S 后焊不形成桥连。
- 断电测 VBAT/SYS/3V45/USB_5V/VOPT/VAA 对地阻值，等待电容充电稳定；记录阻值变化，不以瞬间蜂鸣直接判短路。
- 开始人体连接前，所有电气检查均使用电阻盒或替代负载。普通接地示波器、USB和有线调试器不可带着连接到人体指套。

## 分阶段上电与功能验收

| 阶段 | 方法 | 通过条件与记录 |
|---|---|---|
| 1. 输入与关断 | 不接 USB/电池，J104拉低保持主电源关闭；从 J102 用限流台式电源供电 | 极性正确，无异常静态电流/温升；记录输入电压、电流，确认关断行为 |
| 2. 主电源启动 | 释放 J104，先保持 MCU_EN 低，再允许 MCU 启动；初始用较低限流排短路，确认后按负载和实际供电额定值分级提高 | 限流导致的掉电重启不能误判为电路稳定。记录 SYS、3V45、EN、PWR_GOOD 启动波形和输入峰值；不设旧 100 mA 为通用硬上限 |
| 3. 电源范围 | 在实际电芯有效工作电压范围做高/中/低电压点，覆盖启动和 BLE/传感器负载阶跃 | ESP 模块引脚电压在 3.0～3.6 V 内，JY901S 供电脚达到其允许范围（当前预算下限3.3 V）；记录纹波、欠冲/过冲、焊点压降及温升。3V45静态预算约3.3943～3.5061 V，不替代瞬态测量 |
| 4. 最小固件 | USB 识别、串口日志、LED、复位；初始 CHG_EN/GSR_EN/BAT_SENSE_EN 关闭，业务无线先不开 | 可重复启动，Flash/PSRAM容量和分区匹配 N4R2；没有异常复位原因或默认误激励 |
| 5. USB与恢复 | 分别用 C–C / A–C 数据线、两种插入方向；测试正常应用、空/错误应用、手动下载恢复 | 按住 BOOT→按放 RESET→释放 BOOT，ROM USB Serial/JTAG 可烧录。GPIO46保持默认低；UART0后备下载也验证。USB5V不得接GPIO或3V45 |
| 6. USB电源路径 | 不接人体，切换 USB 接入/拔出及负载 | USB_RAW/USB_5V/SYS/3V45 无异常倒灌和掉电；记录输入限制、系统用电与充电电流分配。仅USB时不足的输入电流可导致限流，不据此提高电芯允许值 |
| 7. 充电与温度 | 用支持吸收充电电流的电池模拟器/合适测试装置，或已确认匹配的电池；再由固件使能充电 | 4.2 V 档、恒流段名义58.8 mA，对照52.42～65.36 mA预算、输入限流与实际电芯规格；充满/再充、NTC开短路、冷热及恢复行为均记录。普通不能吸收电流的台式电源不得当作电池边充边测 |
| 8. JY901S | SMT后人工焊装，复查焊点；GPIO17发往模块RX，GPIO18接模块TX | 电平、波特率、帧校验、实测输出速率/电流、轴向、静止噪声和安装位置正确；记录BLE、USB及电源负载变化时的磁场偏差 |
| 9. ADS1115与GSR | AFE I²C用GPIO4/5、RDY用GPIO6；指套接口先接10 kΩ/100 kΩ/1 MΩ、开路等标准负载 | 记录激励电压/电流、各测试点电压、ADC原码、转换量程、噪声和饱和范围；R319默认DNP，辅助ADC不默认等于主GSR通路 |
| 10. USB激励联锁 | 标准电阻仍接接口，覆盖USB插入、拔出、MCU复位和固件未运行；含固件试图开启GSR_EN的情形 | 插USB时硬件确实阻止皮肤电激励，默认状态也不误开启；记录USB_ABSENT(GPIO14)、GSR_EN(GPIO7)和实际VEX波形。硬件联锁未通过不得接人体 |
| 11. PAT9125EL-TKIT | 先测模块VDD/总线/MOT，再接五针直通线；SCL/SDA为GPIO8/9，MOT为GPIO10 | J401 VOPT来自3V45，不能当作独立精密3.3 V；核对成品板实际供电、上拉及输出电平与两端额定值。I²C开漏，关闭ESP内部上拉；确认芯片身份/七位0x75地址、Δx/Δy、MOT、实际速率和空闲功耗 |
| 12. 微动 | J402接COM/NO，轻压笔芯并释放 | GPIO11低有效；保留原始边沿并验证软件去抖。C405默认DNP，不能假定已有毫秒级硬件消抖 |
| 13. BLE整合 | 从广播到连接/重连逐步增加采样和发送负载 | 最小固件、BLE广播、连接、收发、CPU/Flash/传感器并发、低电压重连逐项测输入峰值；记录持续吞吐、序号、丢包、缓存溢出及复位 |

若某阶段异常，停在该阶段定位并重测；不通过增加限流值掩盖短路、发热或超过器件/实际电芯额定值的问题。JY901S焊装和温度保护已有设计安排，但未到板实测的项目仍填“待测”，不能默认通过。

## 电池接入与整机指标

- [ ] 记录实际电芯/保护板完整型号、标称/充满电压、容量、连续/脉冲放电、脉冲持续时间、允许充电电流及温度范围；本板4.2 V档和充电公差范围必须匹配。
- [ ] 先在台式供电条件测完整负载电流波形。记录分流电阻、带宽及其压降；平均电流不能代替ESP32启动/BLE峰值。确认实际电池和保护板能承受这些工况后再接入电池。
- [ ] 实际电池下重复高/中/低电量启动及BLE/传感器并发测试；低电量报警、关断、保护触发与恢复均可重复。
- [ ] 连续采集目标至少1小时，填写实际采样/发送配置、持续时间、丢包数、最低电压与温度；以测试结果判定，不以容量除典型电流代替。
- [ ] BLE帧包含单调设备时间戳、序号、采样状态和溢出计数；记录每路采集/中断/串口接收的时间定义。JY901S内部处理延迟需量测，统一时间戳不等于已证明固定毫秒级同步误差。
- [ ] 放入当前外壳后检查75 mm后板组件包络、焊点/线束净空、插头可插拔、按钮行程和电池绝缘固定；确认未挤压模块/电池或遮挡光学窗口。
- [ ] 装壳和正常握笔下测BLE距离、吞吐与方向敏感性；PCB天线禁区检查不替代成品无线性能。
- [ ] 纸面轨迹、不同握笔角度、光学工作高度、落笔门控分别实测；抬笔位置丢失按本轮需求不作为验收失败。
- [ ] 标准电阻测试和USB激励联锁通过后，人体佩戴仅使用电池供电，USB、台式电源、示波器和有线调试连接均断开。信号用于项目压力状态研究，不将本原型结果作为临床诊断。
