# R23 当前接口与调试输入

源为同版418焊盘核对通过的后板，以下内容与上电清单一致。

## 操作前必须知道的接口

脚号以 PCB 焊盘号和连接器定位图为准，不能按插头视角自行反向编号。

| 接口 / 控件 | 实际连接与操作 |
|---|---|
| J102 电池 | 1=VBAT、2=GND。测量实际线束极性后接入；不只凭红黑线色 |
| J103 温度 | 1=BAT_TS、2=GND；接实际电池温度检测，不是第二个电源口 |
| J104 电源控制测试区 | 1=PWR_EN、2=GND；短接到地关闭主电源 |
| USB-C | 充电及原生 USB Serial/JTAG 烧录；D−/D+ 对应 GPIO19/20 |
| SW201 / SW202 | SW201=BOOT(GPIO0)；SW202=RESET/EN |
| J501 调试测试区 | 1=UART0_TX(GPIO43)、2=UART0_RX(GPIO44)、3=MCU_EN、4=BOOT_N、5=GND、6=3V45参考 |
| J401 光学 | 1=VOPT(VDD)、2=SCL、3=SDA、4=MOT、5=GND；6/7为接地机械焊脚，不是信号脚 |
| J402 微动 | 1=TIP_RAW、2=GND；接开关 COM / NO，GPIO11 的 TIP_SW 低表示落笔 |
| J301 指套 | 1=E_SLEEVE、2=E_TIP，3/4为未用触点。两极均经过前端限流，不能把任一极直接改接电路 GND |
| J302 模拟测试区 | 依次 VREF、VEX、GSR_S、GSR_OUT、GSR_ADC、GND；7/8为附加地 |

J501 是 **UART0/EN/BOOT，不是 SWD**。外部 UART 用 3.3 V 逻辑，适配器 RX 接 J501-1，TX 接 J501-2，地接 J501-5；J501-6默认仅为目标电压参考。避免 USB、调试器及台式电源的多路供电互相倒灌。ESP32 原生 ROM 支持 USB 烧录，无需预先烧写应用 USB 引导程序；不为普通开发永久烧写 USB/JTAG 相关 eFuse。
