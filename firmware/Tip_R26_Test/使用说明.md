# R26 笔尖微动测试：Arduino IDE

程序：`Tip_R26_Test.ino`，适用已制作的ESP32-S3-MINI-1-N4R2 / R26后板。检测J402常开开关的按下、松开及计数，不测按压力大小，不需要第三方库。

## 1. 接线

先断电，把无源微动开关接 **J402 / TIP**，不要插到同为两针的J102电池口或J103温度探头口。

| 后板接口 | 接到开关 |
|---|---|
| J402-1：TIP_RAW，经R412 / 1 kΩ到GPIO11 | NO（常开端） |
| J402-2：GND | COM（公共端） |

- 两脚常开开关直接接两端，不分极性、不需要额外供电。
- 三脚微动用COM和NO，不用NC。
- 四脚轻触开关（包括此前建议的EVQQ2B03W）用万用表确认“松开不通、按下才通”的两个引脚；不要误接内部一直相通的两脚。
- 后板R411 / 10 kΩ为GPIO11提供上拉：**松开为高、按下为低**。程序使用`INPUT`，不会以内部上拉掩盖R411漏焊问题。
- BOOT / SW201和RESET / SW202是主板按钮，不是本次测试的笔尖开关。

当前电池发烫问题尚未排清，**电池保持断开，只用USB-C供电**。本程序关闭充电、皮肤电激励和电池分压开关；不佩戴指套。其他传感器不必接入。若USB供电也发烫，应断电排查。

## 2. Arduino IDE设置

解压后打开同名文件夹中的`Tip_R26_Test.ino`。开发板包使用Espressif ESP32，设置与前一份光学测试一致：

| 选项 | 设置 |
|---|---|
| 开发板 | **ESP32S3 Dev Module** |
| USB Mode | **Hardware CDC and JTAG** |
| USB CDC On Boot | **Enabled** |
| Upload Mode | UART0 / Hardware CDC |
| Flash Size | **4MB (32Mb)** |
| Partition Scheme | **Default 4MB with spiffs** |
| PSRAM | **QSPI PSRAM**；本程序也可Disabled |
| Erase All Flash Before Sketch Upload | **Disabled** |
| 串口监视器波特率 | **115200** |

选择USB端口并上传。若上传失败，可按住BOOT，按一下并松开RESET，再松开BOOT；重新选择USB端口上传，必要时上传后再按一下RESET。

上传会替换当前运行的光学或GSR测试程序；原有源文件保留。本程序不写Flash记录、不启动BLE/Wi-Fi，不控制电脑鼠标。

## 3. 如何看结果

打开115200串口监视器。默认每200 ms显示状态，消抖后的动作发生时立即额外显示事件。

松开时：

```text
RAW:1  TIP:0  PRESS:0  RELEASE:0  STATE:RELEASED
```

按下一次并保持：

```text
# EVENT PRESSED at ... ms
RAW:0  TIP:1  PRESS:1  RELEASE:0  STATE:PRESSED
```

随后松开：

```text
# EVENT RELEASED at ... ms
RAW:1  TIP:0  PRESS:1  RELEASE:1  STATE:RELEASED
```

**SYS灯按下亮、松开灭**，不用一直盯着电脑。FAULT灯在此程序中保持熄灭，不作为开关接线合格指示。

| 字段 | 含义 |
|---|---|
| RAW | 当前采到的GPIO原始电平，0=低，1=高 |
| TIP | 消抖后的按下状态：1=按下、0=松开；启动初期−1=尚未稳定 |
| PRESS | 程序采到的、经过消抖确认的按下次数 |
| RELEASE | 经过消抖确认的松开次数 |
| STATE | PRESSED=按下，RELEASED=松开，WAIT=启动时等待稳定 |

输入连续保持新电平至少 **10 ms** 才改变TIP并计数。持续按住只计一次；普通按下—松开周期应各增加一次。上电初始状态不计入事件：上电就按住时PRESS仍为0，松开后RELEASE会增加，所以两计数不一定相等。

这是约1 ms循环采样的功能测试，串口打印等可能延长间隔；不能用RAW输出测量完整触点抖动波形，也不是精确书写时序固件。短于10 ms的触发可能被过滤。

## 4. 串口命令

发送小写字母即可，可带换行：

| 命令 | 功能 |
|---|---|
| `s` | 立即显示状态和计数 |
| `z` | 清零两项计数，不改变当前按下状态 |
| `l` | 开关连续/事件输出；关闭输出时仍采样计数，SYS灯仍响应 |
| `h` | 显示帮助和状态 |

## 5. 异常排查

- **始终RAW=1，按了也不变：**检查J402是否插对、插接/焊线是否断路、开关是否选了正确触点、机械顶杆是否真正触发开关。断电拔下开关线，用万用表测开关两端应为“松开断、按下通”。
- **始终RAW=0：**可能接了四脚开关内部相通的一对、用了常闭NC、开关一直被压住，或线束/焊接短路。断电后拔下开关再用USB测试：若变高，优先排查开关与线束；若仍低，查J402/R412/GPIO11对地短路及R411上拉。
- **按下、松开与预期相反：**先排查是否接了NC常闭触点，不要先改代码反转逻辑。
- **不碰开关也频繁计数：**检查插接、焊接、R411上拉和开关接触；10 ms消抖不能修复断续接触。
- **光学没接会不会影响：**不会。此程序仅读取GPIO11，不初始化光学I²C或ADS1115。
- **只有RAW短暂变化、TIP未变：**可能触发不足10 ms或不稳定，先直接按开关测试，再检查笔芯/顶杆的触发行程。

按下/松开正常只证明数字通路可用，不表示触发力、笔芯行程和长期可靠性已经合格。
