# R26 电池供电时激励检查失败

更新：2026-11-04。当前优先使用电池压降诊断，尚未确认实板故障根因。

**最新证据纠正：**用户明确此前“两个PCB焊盘之间11kΩ”读数错误，且无法测量/补焊R301；该值作废，撤回据此推断焊点问题的结论。下面的硬件测点说明仅供参考，不要求继续操作小器件。

**现在先用代码测试：**重新烧录、启动新版上位机，拔USB、电池供电，连接BLE后等待1秒，再按住微动约2秒，点击“复制诊断”。新报告会给出同次开启前电池电压和开启期间采样最低值；操作见[使用说明第9节](使用说明.md)。这检查持续掉压，不排除更短瞬态，也不测3V45/VAA。降低350mV门限不能改变硬件激励电压，因此本版未降低门限。

## 截图能说明什么

用户截图显示电池约 3.94 V、USB 未接入、VEX=0.000 mV、原始 GSR=1.000 mV。程序识别到电池供电且有 ADC 数据，但没有记录失败发生在开启前还是开启后。故障后固件会关闭激励，随后 VEX=0 可能只是正常的关闭结果；当前 ADC 有读数，也不能排除此前短暂通信故障。

USB 检测输入与实际激励开关通路不同，界面“USB 未接入”不证明 Q301/U303 通路一定正常。FAULT 灯还受光学和 IMU 状态影响，不能单凭灯认定哪颗器件坏。

## 先取得一份诊断

1. 用最新压缩包中的完整 `firmware/Pen_R26_Live` 文件夹重新烧录；不能只复制 `.ino` 而漏掉新头文件 `GsrDiagnostic.h`。Arduino 设置见[使用说明](使用说明.md)。
2. 关闭旧上位机，从新版 `software/PenLive/启动上位机.command` 启动。旧解压目录不会自动更新。只换上位机、不换固件时，会显示“当前固件未提供故障快照”。
3. 电池供电、拔 USB、连接 BLE，先不戴指套，按住微动约 2 秒。VEX 的开启检查不依赖皮肤接触，无须戴指套才能通过。
4. 到“电池与皮肤电”窗口查看“激励故障诊断”，点击“复制诊断”。松开后故障记录仍保留；复制的文本同时列出当前读数和故障瞬间读数，二者不要混淆。

| 代码 | 含义 | 后续定位方向 |
|---|---|---|
| E01 | ADC I²C 通信失败 | ADS1115 供电、GPIO4/5 总线及焊接，含瞬时异常 |
| E02 | ADC 配置读回不符 | ADC 型号、总线干扰或配置异常 |
| E03 | ADC 转换超时 | ADC 转换、供电和总线工作状态 |
| E04 | 开启前 1 秒内没有合格的新采样 | 数据是否持续更新；不能认定是激励电路不输出 |
| E05 | 激励关闭时 VEX 超过 ±50 mV | 关闭通路、残留电压、ADC 输入和量程 |
| E06 | 开启后 ADC 数据无效 | ADC 采样状态，旧值不作为故障电压 |
| E07 | 开启后 ADC 数据超过 500 ms 未更新 | ADC 更新时间和程序调度；电压可能是旧采样 |
| E08 | 开启后 VEX 低于 350 mV | 激励参考、开关/联锁，以及到 ADC 的监测通路 |
| E09 | 开启后 VEX 高于 700 mV | 参考分压、开关输出、监测输入和量程 |

快照包括“开启前检查 / 开启后稳定检查 / 有效采集中”和采样距故障的时间。固件每次按下只保留首次失败，松开不会覆盖；下次尝试才开始新记录。上位机保留最近故障，即使后续采集成功也作为历史显示，不等于当前仍在故障。主动断开、重连或板子重启时清理窗口记录；设备仍保存的故障可在重连后再次读到。需要保存时请复制文本。

## 若为 E08，且故障当时 VEX 接近 0

先查参考电压，不直接更换器件或短接联锁。以下按 R26 当前网表核对，采用电池供电、取下指套，用万用表直流电压档：

1. 黑表笔接 **J302-6 / 7 / 8 中任一 GND**，红表笔接 **J302-1（VREF）**。R302=56kΩ、R303=10kΩ，VREF 应约为 `VAA × 10/66`；VAA≈3.45 V 时约 **0.523 V**。不按微动也应有此参考，适合先用普通万用表测量。
2. VREF 为 0 或明显不符时，再查 R301 后的 VAA、R302/R303 实装值和焊接。VREF 正常，再查 U301 缓冲输出 VEX_BUF、U303 和 EXC_EN 控制通路。
3. **J302-2 为 VEX**。低电压失败时开启阶段通常只有约 300 ms 加采样等待，随后自动关闭。报错后用普通万用表读到 0，不能证明开启窗口内始终是 0。需要捕获这一短暂窗口才能区分具体通路问题。
4. 若实际 VEX 在开启窗口正常，而 ADC 快照仍低，再查 R318→VEX_MON→ADS1115 A1 的监测通路。

软件报告中的 `excitation_command` 是输出命令，不是 EXC_EN 引脚实测电平。正常开启时 GPIO7 经 R304=10kΩ 控制 U303；R305=100kΩ 下拉，Q301 负责 USB 硬件联锁。

本次没有放宽门限、延长激励或绕过联锁。软件通过测试不代表实板故障已修复。
