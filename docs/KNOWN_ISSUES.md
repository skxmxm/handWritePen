# 已知问题与实物状态

截至2026-11-06；测量为用户反馈，未独立复测。

## 电池冷启动未解决

电池开关串联在电池与J102之间。直接打开电池时两灯不亮；此前插USB启动、拔USB后可维持工作。曾有失败后短按RESET恢复的观察，但随后按住RESET上电、2秒后释放仍不亮，不能把不同操作混为同一结果。

火花事件之前，在USB断开、电池开关开启、RESET松开且启动失败时：

| 网络 / 测点 | 用户报告 |
|---|---:|
| VBAT / J102-1 | 3.85 V |
| SYS / C103-1 | 1.33 V |
| 3V45 / J501-6 | 2.36 V |
| MCU_EN / J501-3 | 2.36 V |

供电路径：电池→J102→BQ25185 BAT/SYS→TPS63802→3V45。板端电池有电而SYS异常，可能涉及电池/线束启动瞬态、充电芯片供电通路/保护或后级负载，尚未确诊。万用表读数不能排除短瞬态；USB辅助后能运行也不证明电池启动能力满足要求。后续电池标300mAh，连续/脉冲放电能力和保护阈值尚无确证。

## 探测时出现火花，当前暂停上电

用户在探测C103的SYS焊盘时报告火花，随后无法使用；未取得USB恢复后的对照电压。已确认电池与USB均断开，当前无持续发热、鼓胀、异味、烟。是否触发保护或损坏器件未知。小焊盘带电探测有滑动短接风险，已撤回继续带电探测步骤；先检查仪表接法、局部外观及板况，不直接换大电流电池反复试机。

上述历史电压不代表事件后的板况。固件v0.61增加启动灯光，不能修复未建立的主电源。

## 采集及结构边界

- GSR未进行已知电阻/电极接触的完整标定，贴合压力与运动会改变读数。USB联锁保留；NTC仅接充电器，没有提供真实温度数值的独立ADC通道。
- IMU是否有效、真实BLE吞吐、光学目标200Hz、同步误差及续航仍需实板确认；统一时间戳不等于同时采样。
- v0.5结构按36×12×6 mm电池建模，后板实际包络与PAT9125成品板用于占位参考；精确笔芯、光学高度及装配公差仍需试装。
- 最新打印文件是2026-10-30支撑修正版，针对既有首层/支撑失败整理，未以实物打印证明彻底解决。
